# 🗺️ fdf

## Description
A **3D wireframe** viewer in C that renders elevation maps (`.fdf`) in **isometric** projection using **MiniLibX**. Supports zoom, pan, and rotations.

## Features
- Isometric projection (plus an optional second projection)
- Robust map parsing from input files
- Interactions: zoom, pan, rotations, colors
- Graphics window with MiniLibX (Linux)

## Skills gained
- 2D/3D math for graphics (isometry, transformations)
- Event handling and render loop with MiniLibX
- Data structures to represent grids and segments
